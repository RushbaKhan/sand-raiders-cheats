# SAND Raiders Cheats

Enterprise SEO-optimized landing site for **SAND: Raiders of Sophie** cheats.

**Domain:** [sandraiderscheat.com](https://sandraiderscheat.com)

## Stack

- Vite + React + TypeScript
- Tailwind CSS
- Lenis smooth scroll

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## SEO

- Per-route meta tags, Open Graph, Twitter Cards, canonical URLs
- JSON-LD: Organization, WebSite, Product, FAQ, Article, Blog, Breadcrumb, Review
- `public/robots.txt` and `public/sitemap.xml`

## Deploy

Build output is in `dist/`. Connect `sandraiderscheat.com` via Cloudflare after pushing to GitHub.
